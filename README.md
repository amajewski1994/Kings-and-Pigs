# 👑🐷 Kings and Pigs

**Kings and Pigs** is a 2D browser game built with **React**,
**TypeScript**, and **PixiJS**. The project demonstrates real-time
rendering, basic game mechanics, and asset management in a modern web
environment.

The game is deployed using **GitHub Pages**.

------------------------------------------------------------------------

## 🎮 Gameplay Overview

The player controls the **King** character and must defeat all enemies
on each level to advance.

### Levels

-   **Level 1** -- one Pig enemy
-   **Level 2** -- two Pig enemies
-   **Level 3** -- boss fight against the **King Pig**

Each level increases difficulty by adding more enemies.

------------------------------------------------------------------------

## 🧠 What This Project Demonstrates

-   Real-time 2D rendering with PixiJS
-   Sprite and texture loading
-   Basic enemy AI and collisions
-   Level progression system
-   Using PixiJS inside a React + TypeScript app
-   Build and deployment to GitHub Pages

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   React
-   TypeScript

------------------------------------------------------------------------

## ▶️ Run Locally

1.  Clone the repository: git clone
    https://github.com/amajewski1994/Kings-and-Pigs.git cd
    Kings-and-Pigs

2.  Install dependencies: npm install

3.  Start the development server: npm run dev

4.  Open in browser: http://localhost:5173
